# University management app Exceptions collections

A Java console application.

## Tech stack

- Java
- Lombok

## Concepts covered

Collections, console input (Scanner), custom exceptions, exception handling.

## Project structure

- `Exceptions`: GradeException, StudentNotFoundException
- `StudentManagement`: Group, Student
- `src`: Main

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
